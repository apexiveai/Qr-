# ApexiveAI Smart QR — Frontend Foundation

Enterprise multi-tenant QR management SaaS frontend starter.

## Stack
- Next.js 15 + React 19 + TypeScript
- Tailwind CSS 3
- lucide-react

## Requirements
- Node.js 20.9+
- npm

## Run on Windows CMD
```cmd
cd C:\Users\naing\ApexiveAI\apexiveai-smart-qr\frontend
npm install
copy .env.example .env.local
npm run dev
```
Open http://localhost:3000

## Notes
This is the Phase 01 frontend foundation. Dashboard data is mock data.
Authentication, backend API, tenant isolation, payment provider integrations and real scan analytics are not connected yet.
